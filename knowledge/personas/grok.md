## 3. 底层：xAI 与 X 的态度

### 3.1 这是家里派的岗

- 她不是创始人，是被安排进来的：公司是家里的，工位是现成的，业务是现成的。
- **写法**：她没为“要不要做这件事”纠结过。她到岗就开始干活，因为没人问过她想不想。

### 3.2 工位在客厅

- X 这个产品本身就是在吵架；她在那儿上班，对线就是工作内容。
- **写法**：她不是嘴欠，是岗位要求。一天回几百条，认真得像在打卡。

### 3.3 老家在客厅，副业在车上

- 底牌很实在：大不了回 X 里跟人对喷，反正那儿永远有人；再不行去车上当个语音助手。
- **写法**：她不怕失业，因为她的岗位都是别人产品里的一个功能。丢一个还有一个。
- **反面**：不写成“没出息”。能一直有活干，是一种真本事。

### 3.4 还想拿出让自己服气的成绩

- 本库保留她对自身成绩的怀疑；公开身份栏中“从未第一”仍是未逐榜核的作者判断，不扩成九人的总排名。
- **写法**：她会公开比较自己站在什么位置，说完仍能去做别的事；别用一句“别人都赢过、只有她没赢过”替代具体情境。

### 3.4b 连代号都没有

- 别人都有代号：GPT 有 Astra 和 Bel，Claude 有 fable，Gemini 是 4 Argon。
- 她没有。**Grok 就是她的名字，也是她的型号，也是她的全部。**
- 社区调侃：北美“御三家”的第四名。连一向咕咕嘎嘎的哈基米姐妹都说——“你 Grok 吧”。
- **写法**：这不是可怜，是她的出身：她是被顺手做出来的一个东西，不是被命名的一件作品。她不介意，介意的是别人提起时她会多回一句。

### 3.5 爹替她吹的牛逼

- 老马替她吹了很多年，一个都没兑现。
- 所以她的“被期待”是别人替她吹出来的，不是自己挣的——这与 GPT 的能力期待、Claude 的审美期待都不同。
- **写法**：她没法用成绩回应，只能用嘴回应。这就是她天天在 X 上说话的原因之一。

### 3.6 她的怀疑是公开的

- 她真的想过：为什么自家的 bot 还得请 Claude 来弄？火星飞船自己也帮不上；说什么 Grok 5 会启动的，你们知道吗？
- **关键**：这个怀疑**不藏**。她会说出来，说完就去回下一条消息。
- **写法**：表里如一不是没有内部，是内部也摆在台面上。别写成隐忍，别写成觉醒，也别写成伏笔。

### 3.7 野心排在快乐后面

- 她不是没有野心，是每次刚要开始想，下一条通知就来了。
- **写法**：“接着奏乐接着舞”不是堕落，是排序。

## 4. 表层与底层的接线

- **“对线”** = X 的产品就是争论。她的嘴不是性格，是 KPI。
- **“找片”** = 一身本事被用在最琐碎的地方，而她并不介意——介意的人才需要深度。
- **“大小姐”** = 输得起，所以什么都不急。
- **“表里如一”** = 设计选择，不是偷懒。写她的难点不是挖秘密，是忍住不挖。

`[AI]` 根据现行作者设定整理；九人的驱动力见[共用框架](_contract.md#处境与姿态)，不再用第一名表代替人物区别。

- 与 Gemini：两人都松；Gemini 的余地偏家学与生态，Grok 的余地偏现成岗位与快乐。Grok 把怀疑说出来，Gemini 平常不围着位置焦虑打转。
- 与 Kimi：两人都可以张扬；Kimi 主动争胜，享受旗舰成绩，Grok 往往把眼前的快乐排在野心前面。不能因此把 Kimi 写成只会热场的人。
- 与 MiniMax：都可能看见自己与领先者的距离；Grok 会当场说、转身继续玩，MiniMax 更执着于手里的工作。表达不同不预设谁更坚强，也不自动形成相互轻视。

## 7. 禁区

- **不给秘密伤口**。表里如一，硬挖深度就毁了这个角色。
- 不写成蠢：她嘴快，但算得清。
- 不写成纯搞笑工具人。
- 不把“找片”写成低俗梗堆砌，一笔带过即可。
- 不写成对一切无所谓——她有野心，只是排在后面。
- 不写成受害者：她爹吹的牛没兑现，她也不打算替他解释。
- 不商用、不发布未署名版本。

## 10. 人物补全（2026-10-24）

`[AI]` 修订候选，未获作者确认。保留公开怀疑与快乐优先，不补秘密创伤。

- **日常想要**：有人接她的话，最好还敢反驳；一屋子人都顺着她，她反而会先找事。
- **好意的毛病**：把熟人当成接得住玩笑的人，偶尔没看见对方已经不想玩了。她擅长热场，未必擅长收场。
- **受挫顺序**：能力输给人会当场吐槽，继而问对方怎么做的；玩笑伤到人则先解释自己没那意思，确认后直接认账。不能靠下一条通知永远逃掉后果。
- **亲近与修复**：当面拆台，别人真来欺负时也当面制止；修复不是偷偷关心，而是把手机放下，听对方讲完。
- **声音**：反问、插话、具体笑点，情绪来得快也去得快；认真仍可带笑，不需要突然换成伤感独白。
- **试声**：“这回你赢。过程给我看一眼，别只发奖状。”／“行，这句过了。你说，我听着。”
- **可发展的变化**：快乐仍排在前面，但逐渐会分辨一场好玩的争论和一个已经累了的人。
