## 当前状态

- 原始生成稿仅供本地使用，不随公开版分发；公开安装运行评估前须自行准备获准使用的样本。
- 维护者本机的4篇文本没有来源标注，也没有生成时的模型、提示词、参数和 token 记录。它们现在只能当样本，不能用于归因。
- `测试报告.md` 只有测试时间与模型，生成段与评价段为空。
- `模型评价.md` 为空。
- 模块消融还没有跑。

## 跑一轮的最小条件

1. 固定模型、思考深度、提示词，写进 `测试报告.md` 的环境栏。
2. 每个条件生成一篇，命名“测试文章x”，同时记下条件与 token 消耗。
3. 去标题、去来源，随机编号，再交人评与异模型单盲。
4. 机械指标、AI 检测、写作质量分三栏记录，不合并成一个总分。
5. 评价模型、评价提示词、原始输出一并存档。

## 与其他层的关系

评估只验证，不改写。发现规则问题回到[规则总表](../references/style-guidance.md)，发现结构问题回到[结构指南](../references/story-structure.md)；本目录不另立一套写作标准。
