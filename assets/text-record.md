# 篇目与版本登记

| 字段 | 记录内容 |
| --- | --- |
| 篇目ID、题名与题材 | 同篇各版本共用稳定篇目ID |
| 原作者 | 作者本人 / AI / 他人 / 未确定；注明依据 |
| 本版本作者/整理者 | 改稿或誊写由谁完成 |
| 反馈者 | 原始批注的判断归属 |
| 版本类型与日期 | 原稿 / 改稿 / 带批注稿 / 节选 / 对话摘录 |
| 相对前版的关系 | 从哪版修改；未取得前版则明说 |
| 完整程度 | 全文 / 局部 / 仅有过程记录 |
| 实际路径与来源 | 本地文件、用户消息或可定位历史记录 |
| 原始文字与派生处理 | 是否规范誊写、去批注或AI整理；原始版保留 |
| 关联经验与本篇意图 | 链接到同一W编号的作品文件；过程材料使用N编号 |
| 缺口与验证 | 未取得的版本、实际比对情况；迁移时的哈希核对 |

原作者、修改者和提供者分别登记，不能根据文风或发言人推断文本来源。
