# 本篇简报（试行模板）

只填本轮确实需要的内容；已知项由模型从材料提取，不要求作者填表。字段本身为设计提案，可删改。

| 项目 | 内容与来源状态 |
| --- | --- |
| 当前稿件 | 意图 / 骨架 / 血肉稿 / 正文；实际文件或片段 |
| 文本来源与版本 | AI稿 / 作者本人自写稿 / 他人参考 / 未确定；原作者、改稿者、版本与完整程度分别登记 |
| 本轮要求 | 提案 / 填充 / 审查；具体交付范围 |
| 原作与截止点 | 同人为动画、游戏或其他版本及已发生边界；原创为作者已定世界条件，不虚构外部官方来源 |
| 角色 | 本轮角色与关系；引用本轮角色卡，不预设恋爱关系 |
| 表层事件与主要矛盾 | 谁想得到什么，受到什么阻力 |
| 看点与变化 | 作者希望看见什么，当前单元怎样起伏与收束 |
| 视角 | 谁感知、允许访问哪些心理；不在此把句序方法误归为结构原则 |
| 调味 | 原作互文与证据；可选通用机制；本篇独特之处 |
| 锁定与允许新增 | 事件、动机、结局、视角和篇幅；哪些可提案、哪些只可改文字 |
| 知识检索 | 本轮日期、记录路径、已核与待核事实 |
| 作者判断 | 原话或准确摘要；与模型经验候选分开 |
| 本篇意图与候选解释 | 作者确认的主题、人物动机、结尾含义逐项注明来源；助手的读法、修法另标待核，不因导入历史案例自动沿用 |
| 当前缺口 | 只列影响本轮结果的缺口，标明能继续做什么 |

没有新篇意图时，这份表只是模板，不能把试点人物选择算作已有故事委托。
