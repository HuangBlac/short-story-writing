# 公开分发与本地资料

公开署名使用黄晓黑。学校邮箱账号中的编号是学号，不作为生日记录，也不随公开版分发。第三方公开作者与研究资料的署名保持来源归属。

作者允许公开的私人原话、写作偏好与经验分析可以保留；公开前过滤内部聊天或会话编号、聊天链接、本机绝对路径和学号邮箱。

<a id="local-materials"></a>
## 仅本地保存的材料

- `knowledge/texts/`中的原稿、修订稿、完整批注、原始聊天摘录及原始版本登记；`index.md`为可公开的导航目录。
- `fanfiction-workbench/`中的近期工作稿、简报、自评与修订。
- `test/`中的`测试文本*.md`原始生成稿；评估方法与空白记录模板可以公开。公开安装不附原始样本，运行评估需自备获准使用的样本。
- `knowledge/research/*-evidence.json`原始取证清单、本机图片路径与来源会话信息。
- `maintenance/raw-baseline.json`、`maintenance/annotation-baseline.json`和`debug.log`。

本机原件保留实际字节与原始来源，不对原件做脱敏改写。公开经验中的“仅本地”入口表示该原件不随分发；需要追溯时，本机维护者按作品编号读取对应目录。没有原件的公开安装只能使用已提供的分析与公开资料，不假定原始材料已随包附带。

## 制作公开版本

原始材料由Git忽略并退出当前跟踪；导出忽略规则作为归档的额外防线。公开包从完成脱敏检查的当前跟踪文件构建，不能直接压缩整个安装目录。不得将本机`.git`、本地历史备份或`archive/`引用带入公开版本，也不使用`push --all`或`push --mirror`上传维护历史。

本地维护仓库可能保留历史原件、学号邮箱与内部来源，不能直接把完整维护历史改为公开。公开Git版本从审核后的分发文件建立独立根提交，作者与提交者使用黄晓黑及GitHub隐私邮箱。改动公开权限、替换线上版本和处理旧附件分别核对；本文件不是已经发布或已经清理线上历史的回执。

v0.1.0 使用新建的干净仓库承载公开版本；已有私有仓库改名后继续保持私有，旧对象、旧标签和旧 Release 不导入公开仓库。上传限定为一个经过审核的分支与对应版本标签，不从本机维护仓库推送。
