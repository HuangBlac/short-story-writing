# 经验接收、格式与回流

作者可只给判断、改句、批注或感受，AI负责整理。接收AI稿、作者自写原稿与改稿、跨题材片段及过程复盘，使用[证据标签](../SKILL.md#证据标签)。

## 资料流

| 材料 | 保存位置 |
| --- | --- |
| 原稿、改稿、原始批注 | [knowledge/texts](../knowledge/texts/index.md)，按[存稿规则](manuscript-archive.md)登记 |
| 单篇整体分析、具体改法 | experience/works/W编号文件 |
| 本篇事件、动机、场景与人物笔记 | 同一作品文件中的相应节 |
| 跨篇候选规则 | references/style-guidance中的R编号行，标候选状态 |
| 编辑过程记录、跨篇研究线索 | experience/records/N编号文件、experience/notes |
| 当前规则正文与范围 | [style-guidance](style-guidance.md)中的对应编号行 |

每项内容设一个主要维护位置，其他位置用链接引用。作者要求维护安装skill时，完成实际写入并核对。

## 逐篇整理

使用[经验条目模板](../assets/experience-entry.md)，先写整体经验，再附细粒度批注：

1. **材料与版本**：作品、作者、改稿者、反馈者、来源、文本路径与完整程度。
2. **整体经验**：本篇想做什么，哪些过程成立，主要问题是什么。
3. **结构与文字**：定位问题、原改关系、作用、具体改法与适用条件；改变锁定内容的提案标明授权状态。
4. **风格与感受**：作者评价与AI解释分别标记来源、范围；人物心理分析限定于作品中的人物。
5. **规则变更**：规则ID、证据链接、补证/例外/缩小/替换/拒绝/未修改，以及实际维护位置。
6. **接续**：已完成的修改与验证、待取得材料、待核事实和下一步。

按实际材料填写，缺项简记“未取得”。

## 规则更新

将反馈接到已有规则ID：当前用法与范围只改[总表](style-guidance.md)的对应行；案例只补本篇证据、变更类型与规则链接，方法指南保留操作步骤并链接规则。已有引用无需随措辞变更重写。规则范围扩大时按[R008](style-guidance.md#r008)处理；跨篇候选仍放同一总表并标候选状态。

## 新旧材料与冲突

同篇反馈接续原编号，重复段落只补新增判断。冲突按具体位置与版本保留，实例见[W003待协调项](../experience/works/W003-still-life.md#尚待协调与验证)。

原始笔误、工作注与未完成示范按存稿规则保留；规范誊写另存派生版本。新增动作、动机、事实或结局遵循本轮编辑权限。

## 验证记录

以篇目和材料类型统计样本。分别报告文件与引用检查、原作一致性核对、实际改稿、作者接受及跨篇试用结果；结果填写到对应篇目的接续栏。
