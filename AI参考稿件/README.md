# 参考稿件投稿

这里收使用者自愿提交的短篇：一篇 `brief.md` 加一篇 `manuscript.md`，成对保存，给后面写作时当参考。

投稿完全可选。满意、接受稿件或本地存档都不等于同意公开上传；没有明确授权就不上传、不建 PR。

## 目录与文件

每篇一个子目录，命名 `作者名-短名`：

```
AI参考稿件/
└─ 你的名字-篇名/
   ├─ brief.md        # 本篇简报：角色、剧情进度、范围、锁定内容
   └─ manuscript.md   # 正文，按原文保存，不改字
```

`brief.md` 用[本篇简报模板](../assets/story-brief.md)；模板里的字段不必全填，缺的写"未定"。

## 怎么交

1. Fork 本仓库，在 `AI参考稿件/` 下新建目录，放两个文件。
2. 提交 PR，标题写"参考稿件：作者-篇名"。
3. 在 PR 说明里写三件事：用了哪个模型和客户端、对应哪一版设定、愿意以什么范围授权（仅供本仓库阅读参考，还是允许二次分发）。

不需要先过审稿或评分。被收录也不代表维护者认可这篇写得好，或者里面的做法已经验证过。

## 授权

投稿者保留自己作品的版权。投稿即授权本项目在仓库内保存这些文件，供其他使用者阅读和写作时参考；不授权商业使用，也不承诺替你发表。

本目录中的投稿作品不自动适用仓库根目录的 CC BY-NC-SA 4.0，具体以投稿者明确的授权为准。仅获仓库阅读参考授权的作品，二次分发前须另获许可；不因合并 PR 扩大授权范围。

不想公开时，把稿子留在本地就行，技能不会因此少任何功能。
